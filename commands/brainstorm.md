Use the **brainstorming** skill from the cozypowers plugin.

Take the idea I describe (or ask me for it if I haven't yet) and run the full brainstorming process: one question at a time, 2-3 alternative approaches with trade-offs, design presented in short sections for my approval, and the approved design saved to `docs/designs/`. Do not write implementation code during this command.
