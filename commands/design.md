description: Design or review an interface using the local design corpus
---

Use the **designing-interfaces** skill from the cozypowers plugin.

Take the interface work I describe (or ask me what I'm building if I haven't said
yet) and run the full procedure: read the situation and detect the stack rather
than assuming it, search the corpus in `skills/designing-interfaces/data/` with
Grep, and synthesise one coherent design system rather than a pile of search
results. Fix things in priority order - accessibility and touch targets before
aesthetics. Before calling it done, run the pre-delivery checklist.

If a search returns nothing, say so and tell me the recommendation came from the
built-in priority table. Never cite a corpus row you did not actually read.
